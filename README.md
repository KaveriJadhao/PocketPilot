# 🧭 PocketPilot

**PocketPilot** is a smart, simple expense tracker designed for college students. Track daily spends with Voice AI, manage your monthly allowance, and stay on budget with personalized AI insights.

---

### 🌐 Live Demo
👉 **[https://pocket-pilot-three.vercel.app/](https://pocket-pilot-three.vercel.app/)**

---

### ✨ Features
- 🎙️ **Voice AI Logging** — Speak naturally to log expenses in seconds.
- 📊 **Budget Cockpit** — Real-time tracking of monthly allowance and daily limits.
- 📈 **Visual Analytics** — Category breakdowns and weekly spending trend charts.
- 😊 **Mood Tracking** — Understand emotional triggers behind your spending.
- 🎁 **Streaks & Rewards** — Earn gems and level up for consistent tracking.
- 🧠 **AI Coaching** — Daily personalized tips to help you save money.
- 🌓 **Dark & Light Mode** — Clean, responsive interface for mobile and desktop.

---

### 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Chart.js, Web Speech API
- **Backend**: Node.js, Express.js, JWT Authentication
- **AI & DB**: Groq Llama 3.3 AI, MongoDB / Local Storage Fallback
- **Hosting**: Vercel

---

### 🚀 Run Locally

```bash
# 1. Clone repo
git clone https://github.com/KaveriJadhao/PocketPilot.git
cd PocketPilot

# 2. Install dependencies
npm install

# 3. Start server
node Backend/server.js
```

Open **`http://localhost:5000`** in your browser.
