# PocketPilot 🧭

PocketPilot is an AI-powered expense tracker designed for students to manage spending, track moods, earn rewards, and receive personalized financial insights.

## 🚀 Features

- User Login & Signup
- Onboarding Experience
- Expense Tracking
- Budget Management
- AI Financial Insights (Groq AI)
- Mood-Based Spending Tracker
- Rewards & Gems System
- Level Progression
- Smart Alerts
- Analytics Dashboard
- Dark Mode
- Voice AI Interface
- MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### AI
- Groq API (Llama 3.3 70B)

## ⚙️ Installation

### Clone Repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### Install Backend Dependencies

```bash
cd Backend
npm install
```

### Create .env File

```env
MONGO_URI=your_mongodb_connection_string
GROQ_API_KEY=your_groq_api_key
```

### Start Server

```bash
npx nodemon server.js
```

### Run Frontend

Open with Live Server in VS Code.
